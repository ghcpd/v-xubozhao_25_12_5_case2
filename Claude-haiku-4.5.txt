## Solution: Sliding Window Maximum

**Algorithm**: Uses a **deque (double-ended queue)** to efficiently track the maximum in each window.

**Key idea**:
- Store indices of array elements in the deque, ordered by value (largest at front)
- Remove indices outside the current window
- Remove smaller elements that can never be maximum while larger elements exist
- The front element is always the maximum for the current window

**For your example**:
- `nums = [1,3,-1,-3,5,3,6,7]`, `k = 3`
- **Output**: `[3, 3, 5, 5, 6, 7]`

**Complexity**:
- **Time**: O(n) - each element processed once
- **Space**: O(k) - deque size bounded by window size

The solution is saved in sliding_window_maximum.py and handles edge cases (empty arrays, k=0, etc.).
