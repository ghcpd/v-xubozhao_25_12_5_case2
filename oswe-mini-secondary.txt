✅ Solution — Sliding Window Maximum (k=3)

## Problem
Given nums = [1, 3, -1, -3, 5, 3, 6, 7] and k = 3, return the maximum for every sliding window of size k as it moves from left to right.

---

## Solution (Python)
This uses a monotonic deque (indices kept in decreasing order of values) for O(n) time.

```python
from collections import deque
from typing import List

def max_sliding_window(nums: List[int], k: int) -> List[int]:
    if not nums or k == 0:
        return []
    if k == 1:
        return nums[:]  # every element is a window

    dq = deque()  # store indices of elements, values decreasing
    res = []

    for i, val in enumerate(nums):
        # remove indices out of the current window (leftmost)
        while dq and dq[0] < i - k + 1:
            dq.popleft()

        # remove from right all indices with smaller values than current
        while dq and nums[dq[-1]] < val:
            dq.pop()

        dq.append(i)

        # when we've processed the first k elements, record the max
        if i >= k - 1:
            res.append(nums[dq[0]])

    return res
```

## Explanation & Complexity
- How it works: The deque keeps indices of candidates for the max in the current window in decreasing order of their values. For each new element we remove indexes outside the window and pop smaller values from the back, ensuring the front of the deque holds the current window maximum.
- Time complexity: O(n) — each element index is pushed and popped at most once.
- Space complexity: O(k) worst-case for the deque.
