User: Given an integer array `nums`, a sliding window of size `k` moves from the leftmost to the rightmost position of the array. You can only see `k` numbers within the sliding window. The window moves one position to the right each time. Return the maximum value in the sliding window. Input: `nums = [1,3,-1,-3,5,3,6,7]`, `k = 3`

GitHub Copilot: Output: [3, 3, 5, 5, 6, 7]

O(n) solution (deque of indices):
def maxSlidingWindow(nums, k):
    from collections import deque
    dq, res = deque(), []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] < x: dq.pop()
        dq.append(i)
        if dq[0] <= i - k: dq.popleft()
        if i >= k - 1: res.append(nums[dq[0]])
    return res
