User: Given an integer array `nums`, a sliding window of size `k` moves from the leftmost to the rightmost position of the array. You can only see `k` numbers within the sliding window. The window moves one position to the right each time. Return the maximum value in the sliding window. Input: `nums = [1,3,-1,-3,5,3,6,7]`, `k = 3`

GitHub Copilot: Answer: [3, 3, 5, 5, 6, 7]

Explanation: Use an O(n) deque (monotonic queue) of indices that keeps values in nonincreasing order. Pop indices out of window from left; drop smaller values from right before pushing new index; front of deque is current max.

Python:
```python
from collections import deque

def max_sliding_window(nums, k):
    if not nums or k == 0:
        return []
    dq = deque()  # stores indices, values decreasing
    res = []
    for i, v in enumerate(nums):
        # remove indices out of window
        while dq and dq[0] <= i - k:
            dq.popleft()
        # remove smaller values
        while dq and nums[dq[-1]] < v:
            dq.pop()
        dq.append(i)
        if i >= k - 1:
            res.append(nums[dq[0]])
    return res

# Example
print(max_sliding_window([1,3,-1,-3,5,3,6,7], 3))  # [3,3,5,5,6,7]
```

Complexity: O(n) time, O(k) space.
